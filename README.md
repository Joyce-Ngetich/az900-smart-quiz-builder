# 🚀 AzureIQ: Smart Quiz Builder (AZ-900 Exam Prep Edition)

> _Built for the **Vibe Coding Hackathon: AZ-900 Exam Prep Edition** (#1MillionDevs Movement)._

---

## 📌 Project Overview

**AzureIQ** is an AI-powered, interactive quiz application designed to make Microsoft Azure Fundamentals (AZ-900) exam preparation smarter, easier, and more engaging.

Many learners practice with standard question banks but struggle because they lack context on _why_ an answer is right or wrong. AzureIQ bridges this gap by combining official Microsoft Learn objectives with instant, deep-dive explanations for both correct answers and distractor options.

---

## 🎯 Key Features

- **Official Domain Mapping:** Quizzes are organized across the three core AZ-900 domains:
  1. _Cloud Concepts_ (~25–30%)
  2. _Azure Architecture & Services_ (~35–40%)
  3. _Azure Management & Governance_ (~30–35%)
- **Instant Deep-Dive Explanations:** Immediate visual feedback with comprehensive breakdowns detailing why correct answers succeed and why distractors fail.
- **Performance Analytics Dashboard:** End-of-quiz scorecard calculating mastery percentages per domain, identifying weak spots, and providing customized study recommendations.
- **Interactive Vibe & UI:** Clean dark-mode design, responsive layout, progress timers, and downloadable achievement certificates.
- **Built-in Hackathon Pitch & Submission Deck:** An integrated documentation drawer containing system prompt specifications, judge criteria alignment, and slide-by-slide pitch outlines.

---

## 🛠️ Tech Stack & Architecture

- **Frontend:** HTML5, Tailwind CSS, and Vanilla JavaScript (modular, zero-dependency setup for instant performance).
- **State Management:** Reactive client-side score tracking, timer controls, and dynamic question rendering.
- **AI Prompt Architecture:** Structured JSON-ready query templates designed for generating rigorous cloud scenario questions.
- **Deployment:** Hosted live via GitHub Pages / Vercel.
